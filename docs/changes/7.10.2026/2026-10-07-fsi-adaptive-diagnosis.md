# Изменение — адаптивная расшифровка FSI 4.1

**Дата:** 07.10.2026  
**Время (МСК):** 17:37+

## Изменённые файлы

- `source/index/finance/finance.index.js` — добавлен диагностический слой FSI 4.2 поверх зафиксированной формулы FSI 4.1.
- `source/application/finance/finance.js` — добавлено получение исторического состояния примерно месяц назад и сравнение с текущим FSI.
- `source/presentation/finance/finance.js` — подключена адаптивная пользовательская расшифровка динамики FSI.

## Что реализовано

- Сама математическая формула FSI 4.1 не изменена.
- Добавлено определение изменения индекса относительно сопоставимого исторического состояния.
- Определяются факторы с наибольшим положительным и отрицательным вкладом через изменение компонентов и их веса.
- Определяется наиболее слабый компонент текущей финансовой системы.
- Текст диагностики формируется индивидуально для пользователя, а не выбирается по диапазону шкалы FSI.
- При отсутствии достаточной истории система не выдумывает динамику и сообщает об отсутствии сравнения.
- При росте индекса пользователь получает объяснение основных факторов улучшения.
- При снижении индекса пользователь получает объяснение основных факторов ухудшения.
- Слабое звено выводится только при существенной выраженности проблемы.

## Архитектурное решение

FSI разделён на два логических уровня:

1. **FSI 4.1** — математический расчёт финансовой устойчивости.
2. **Adaptive Diagnosis** — интерпретация динамики конкретного пользователя.

Диагностика не меняет числовой результат индекса и не подменяет его универсальными рекомендациями.

## Статус

Изменение реализовано. Требуется пользовательская проверка текста на реальных исторических данных Finance.
