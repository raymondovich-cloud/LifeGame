# Изменение: видимый экран Finance

**Дата и время:** 1 октября 2026 года, 07:42:18 MSK (UTC+03:00)

## Изменённые файлы

- `platforms/web/index.html` — Version 1.4 → Version 1.6
- `platforms/web/web.js` — Version 1.1 → Version 1.2
- `source/application/finance/finance.js` — создан, Version 1.0 → Version 1.1
- `source/design/components/accordion.css` — Version 1.0 → Version 1.1

## Что изменено

Создан первый видимый экран Finance с пятью подблоками:

1. Ликвидные средства
2. Фактически заработано
3. Финансовая нагрузка
4. Обязательные траты
5. Финансовая подушка

Каждый подблок представлен единым Accordion-компонентом Design System.

Подблоки можно раскрывать и сворачивать нажатием на заголовок.

Finance screen подключён к существующей навигации через отдельный application-модуль. При выборе Finance экран становится видимым, при переходе на другой модуль скрывается.

## Архитектурное решение

Навигация приложения не изменялась. Поведение Finance вынесено в `source/application/finance/finance.js`.

Бизнес-логика пяти финансовых категорий остаётся в `source/domain/finance` и не зависит от интерфейса.

## Причина изменения

Переход от невидимого доменного каркаса к реальному пользовательскому экрану Finance.

## Итоговый статус

**Завершено.**

Экран Finance подключён и содержит пять базовых подблоков.
