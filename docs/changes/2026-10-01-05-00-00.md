## Версии

## Что именно создано

Создан каркас Design System без реализации конкретного визуального языка.

Файлы разделены по архитектурной ответственности:

- `tokens` — визуальные токены;
- `foundation` — базовые правила;
- `components` — переиспользуемые UI-компоненты;
- `patterns` — составные UI-паттерны;
- `themes` — визуальные темы;
- `design.css` — единая точка входа Design System.

`design.css` содержит подключения всех модулей Design System через `@import`.

## Причина изменения

Необходимо было физически создать утверждованный каркас `source/design`, чтобы дальнейшая разработка визуального слоя LifeGame происходила внутри заранее определённых архитектурных границ.

## Архитектурные решения

1. Design System веб-версии реализуется на CSS.
2. JavaScript не добавляется в `source/design`.
3. Каждый CSS-файл имеет одну визуальную ответственность.
4. Каркас создаётся отдельно от последующей реализации конкретных стилей.
5. `design.css` используется как единая точка входа.
6. Бизнес-логика в Design System отсутствует.
