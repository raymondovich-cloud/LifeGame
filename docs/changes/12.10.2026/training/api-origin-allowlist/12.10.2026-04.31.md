# Training API — исправление allowlist источников

- Дата: 12.10.2026

- Пользовательский запрос: исправить ошибку `Training Overview API: remote request failed.`

## Диагностика

- В журналах Supabase обнаружены повторяющиеся HTTP 403 на POST-запросах к обеим Edge Functions: `training-programs` и `training-sessions`.
- JWT в этих запросах распознан как принадлежащий авторизованному пользователю; обе функции активны.
- Обе функции проверяют Origin до основной обработки запроса и возвращают 403 для источника, отсутствующего в allowlist.
- В развёрнутых entrypoint явно добавлен только домен GitHub Pages; `https://lifegame.site` не был явно включён в исходный allowlist. Значение серверной переменной `TRAINING_ALLOWED_ORIGINS` не раскрывалось и не изменялось.

## Изменения

- `supabase/functions/training-programs/index.ts`: Version 1.0 -> 1.1.
- `supabase/functions/training-sessions/index.ts`: Version 1.2 -> 1.3.
- В оба allowlist явно добавлены точные HTTPS-origin `https://lifegame.site` и `https://raymondovich-cloud.github.io`; существующие значения `TRAINING_ALLOWED_ORIGINS` сохранены.
- Wildcard-origin не используется. Проверка авторизации, JWT, ownership, RLS и шифрования не ослабляется.
- Новые зависимости и изменения бизнес-логики не добавлены.
