LifeGame — это персональная система, которая помогает человеку понимать самые важные области своей жизни.

◼ МЕНЬШЕ ШУМА. БОЛЬШЕ ЯСНОСТИ.

LifeGame следует одному фундаментальному правилу:

Если что-то не делает твою жизнь понятнее — возможно, этому не место в системе.

Никаких бесконечных панелей.

Никакой информационной перегрузки.

Никакой ненужной сложности.

Никаких функций только потому, что их можно добавить.

Каждый элемент должен иметь смысл.

Каждый экран должен иметь причину существовать.

Каждая информация должна помогать человеку понять что-то действительно важное.
